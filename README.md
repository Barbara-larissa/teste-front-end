## 💡 Sobre o projeto

A aplicação apresenta uma interface de e-commerce desenvolvida com React e TypeScript, seguindo o layout de referência do Figma e consumindo dados de produtos em JSON.

---

## 🚀 Tecnologias utilizadas

| Tecnologia | Descrição |
| ---------- | --------- |
| **React** | Biblioteca para construção da interface |
| **TypeScript** | Tipagem estática |
| **Vite** | Ferramenta de build e servidor de desenvolvimento |
| **Sass (SCSS)** | Pré-processador de estilos |
| **HTML5** | Estrutura das páginas |
| **CSS3** | Estilização |
| **Fetch API** | Consumo de dados |

---

## ✨ Funcionalidades

- ✅ Interface baseada no layout do Figma.
- ✅ Listagem dinâmica de produtos.
- ✅ Consumo de dados de produtos em JSON.
- ✅ Exibição de imagens, nomes e preços.
- ✅ Modal com informações do produto selecionado.
- ✅ Controle de quantidade na modal.
- ✅ Carrosséis de produtos.
- ✅ Seções de categorias e marcas.
- ✅ Componentes reutilizáveis.
- ✅ Layout responsivo.
- ✅ Tratamento de carregamento e erros na busca de produtos.

---

## 🔗 Fonte dos dados

Os dados dos produtos são disponibilizados pelo endpoint fornecido para o teste técnico:

```
https://app.econverse.com.br/teste-front-end/junior/tecnologia/lista-produtos/produtos.json
```

> Durante o desenvolvimento local, o Vite utiliza um proxy para encaminhar as requisições ao endpoint.

## ⚙️ Como executar o projeto

**1. Clonar o repositório**

```bash
git clone https://github.com/Barbara-larissa/teste-front-end.git
```

**2. Acessar a pasta**

```bash
cd teste-front-end
```

**3. Instalar as dependências**

```bash
npm install
```

**4. Iniciar o projeto**

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para acessar a aplicação pelo navegador.

---

## 🧰 Outros comandos

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```
